## `> sobre_mim`

Oi, eu sou o **João Victor**. Sou brasileiro, moro em Portugal e estou estudando **desenvolvimento web full stack** no curso da **TwoFold**.

Hoje trabalho dos dois lados da aplicação: a interface em **React + Tailwind**, a API em **Node.js + Express** e os dados em **PostgreSQL** e **MongoDB**. No meu projeto final eu montei tudo do zero: banco, autenticação, testes, CI e deploy.

Meu foco é entender cada decisão técnica. Não basta funcionar, eu quero conseguir explicar *por que* funciona.
